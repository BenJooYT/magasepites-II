# Koszorúk

Monolit vasbeton gyűrű minden teherhordó falon, födémsíkban (EC2).

## Feladata
- terhek egyenletes elosztása, födém + fal együttdolgozása
- merevítés (szél, földrengés), koszorúba kötnek a gerendák
  kiálló hosszvasai
- nyomott övként is beszámítható áthidaló felett (megfelelő
  magasság + minőség esetén)

## Kialakítás
- Porotherm 30 U zsalu (300×238×240 mm, ~7,5 kg) bennmaradó zsaluként,
  modulban illeszkedik
- vasalás tipikusan 4×Ø10–12 + kengyel (terv szerint!)
- min magasság ~15–25 cm, végigfutó, sarkokban átvezetett vasalás
- külső oldalon hőszigetelés (Multipor / XPS / homlokzati EPS
  folytonossága) – ez a leggyakoribb hőhíd, ha lehagyják

## Vizsgatipp
Metszet: U-zsalu + vb mag + kívül szigetelés + födém bekötés.
Mondd: „teherelosztás + merevítés + födémfogadás”.
