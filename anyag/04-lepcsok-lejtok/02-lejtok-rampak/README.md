# Lejtők, rámpák

## Általános lejtéskorlát
- gyalogos útvonal: max **8%**
- rendszeres kézi teherszállítás: max **10%**
- szabadban: max **15%**

## Akadálymentes (vizsga!)
- 17 cm szintkülönbségig: max **8% (1:12)**
- nagyobb szintkülönbségnél: **5%** ajánlott
- max **9,00 m** karhossz után min **1,50 m** pihenő
- tört járóvonalnál min **1,5×1,5 m** forduló (kerekesszék)
- többkarúnál minden 2. kar után két kerekesszék találkozásához
  szükséges hely
- épületen belül többkarú max **1,8 m** szint / kar
- szabadban: csapadékvédelem vagy csúszásgátló bordázat

## Kialakítás
- csúszásmentes járófelület, oldalsó lesodródás-gátlás,
  korlát/mellvéd, vízelvezetés szabadban
