# Boltozatok (történeti)

Ma már csak meglévő / műemlék épületeken, de vizsgán vázlat + név kell.

- **donga**: egy irányban íves, hosszan futó (födémként főleg pincefödémnek)
- **csehsüveg (porosz süveg)**: acélgerendák közötti kis dongák
- **keresztboltozat**: két donga áthatása, pillérre terhel
- anyag: tégla, kő; működés: nyomott ív, vállnyomás!
- felújítás: vállmerevítés, hézagkiöntés, acél vonóvas

## Szakkifejezések (vizsgán jól jön)
- **vezérgörbe**: a görbe, amelynek mozgásából a boltozati felület származik
- **intradosz**: a boltozat belső (alsó) felülete
- **extradosz**: a boltozat külső (felső) felülete
- **záradékvonal**: az ív legmagasabb pontján, a tengellyel párhuzamos vonal
- **fiokboltozat**: a zárt boltozatfelület (pl. donga) áttörése nyílásképzéshez
