# Szerelt, réteges válaszfalak

Száraz technológia, kis helyszíni élőmunka. Iroda, középület, átalakítás.

## Rendszerek
- **vázas**: helyszínen állított függőleges/vízszintes váz + burkolótábla
  (pl. acél CW/UW + gipszkarton). Fokozott akusztikánál dupla,
  eltolt váz + ásványgyapot paplan a légrésben.
- **panelos (keretes)**: üzemben kész helyiségmagas panelek sorolása,
  magas készültség, de kötött méret. Áthelyezhető falnak legjobb.
- **vegyes**: váz + előregyártott panel kombinációja.

## Anyagok
- váz: fa, acél, extrudált alumínium
- burkolat: gipszkarton, farost, forgácslap (műanyag-/cementkötésű),
  acél/alu/műanyag lemez, üvegtábla, eternit
- betét: ásványgyapot paplan/lemez (hang!)

## Rögzítés, részletek
- padlóra-mennyezetre erősített vezetőléc / feszítéses megoldás
- paneloknál szalagraszter + bepattintható takaróprofil
  (vezeték elvihető benne, merőleges fal csatlakoztatható)
- súlyos tárgy: vázas falnál a vázra, panelosnál beépített
  szerelőkeretre/bordára
- hazai példák voltak: KŐZFAL acélvázas gipszkarton, PRE-M-ISOL
  fakeretes-gipsz bordás, Gyproc, Sitraplast / CLOISALL alu profil
- rokonok: szekrényfal (tárol + térelválaszt + jó hangszigetelés),
  paravánfal (nem ér mennyezetig, tagolással stabilizálva)

## Vizsgatipp
Rajzold: UW alsó-felső sín + CW oszlop + 2× gipszkarton + gyapot.
Mondd: „száraz, gyors, átszerelhető, akusztika a réteggel”.
