# 01 – Függőleges nem teherhordó szerkezetek (válaszfalak)

A födémre támaszkodnak (földszinten alapozásra/aljzatbetonra).
Nem hordanak födémterhet, de saját súly + függesztett tárgy + ütés + hang + tűz.

## Követelmények (vizsgalista)
- szilárdság, merevség (kihajlás, kiborulás ellen)
- véshetőség, szegezhetőség, alakíthatóság
- vakolattartás, burkolhatóság
- hő- és hangszigetelés, tűzbiztonság (EI), légzárás
- szerelvényezhetőség, flexibilitás/átszerelhetőség
- kis önsúly, gazdaságosság

## Csoportok
- `01-falazott/` – kézi falazóelemes (tégla, kerámia válaszfallap, Ytong, gipsz)
- `02-monolit/` – rabic + vasbeton (ma csak speciális helyen)
- `03-szerelt/` – vázas / panelos / vegyes, gipszkarton, üveg, mobil
