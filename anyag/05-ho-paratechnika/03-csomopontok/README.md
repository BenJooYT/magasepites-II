# Csomópontok, hőhidak, rétegrend

## Tipikus hőhidak (rajzold!)
- áthidaló / koszorú síkja (Thermo áthidaló vagy a külső szigetelés
  folytonossága)
- erkélylemez átvezetés (hőhídmegszakító vagy külön szerkezet)
- lábazat / talajcsatlakozás (XPS + vízszigetelés)
- ablakbeépítés (tok a szigetelés síkjában, légzáró szalag)
- padlásfeljáró, gépészeti áttörés

## Rétegrend-szabály
- belül: légzárás + párafékezés (fólia, átlapolás, ragasztás)
- kívül: páraáteresztő, szélzáró, csapadékvédelem
- szigetelés folytonos, hézag nélkül, átfedéssel / két rétegben eltolva
- lapostető: lejtés + párazáró réteg + hőszigetelés + vízszigetelés sorrend!

## Penészvédelem
- `fRsi`, szellőzés (hővisszanyerős!), bútor mögötti átszellőzés,
  hőhídmentes sarok, ablakkáva-szigetelés
