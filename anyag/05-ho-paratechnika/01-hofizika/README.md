# Hő- és párfizika alapok

- `λ` hővezetés, `R` ellenállás, `U = 1/R` átbocsátás (W/m2K)
- `ψ` vonalmenti hőhíd, `χ` pontszerű (dűbel, konzol)
- páradiffúzió: `μ` ellenállási szám, `Sd` egyenértékű légréteg
- harmatpont: ahol a pára kicsapódik → penész, fagyás, korrózió
- felületi hőmérséklet-tényező `fRsi >= 0,7` (penészvédelem)
- hőtárolás: „nehéz” épület (>400 kg/m2 aktív tömeg) segít KNE-nél
- nyári hővédelem: árnyékolás (külső!), üveg `g`-érték, átszellőzés
